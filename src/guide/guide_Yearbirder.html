What's New

What's New in v2.11

  • Browse Grid — A second way to browse your photos: Photos → Browse Grid shows the photos matching your filters as a grid of thumbnails rather than one card per row. It is built for large results — a filter returning a thousand images, or the hundred-odd photos you may have of a single species, is far quicker to scan several across at a time. Each cell shows the species name, with the full details on hover; click any cell to open the Enlargement view. The grid offers the same four sorting options, the same Slideshow button, and the same live updates as the card view, and reflows to fit as many columns as the window is wide. Thumbnails for the grid are prepared when you add photos to the catalog, so it opens quickly even on a large collection. See Section 21 — Browse Grid.
  • Browse Grid for recordings — Recordings → Browse Grid does the same for your sound recordings, showing them as a grid of spectrograms instead of one card per row. Every cell keeps its own Play button and scrubber, so you can audition a recording without leaving the grid, and clicking a spectrogram opens the Recording Enlargement view as before. See Section 27 — Browsing and Playing Recordings.
  • Browse Photos is now Browse Cards — The original photo browser is unchanged but renamed, so the two views read as a pair on the Photos menu: Browse Cards for one photo per row with its full details alongside, Browse Grid for scanning many at once. The recordings browser is renamed the same way, and the Photos and Recordings toolbar buttons now open the grid views. See Section 21 — Browse Cards.

Quick Start

1. Quick Start

This section gets you from a fresh install to your first results in five minutes.

Step 1 — Download your eBird data

With a browser such as Chrome, Safari, or Edge, go to https://ebird.org/downloadMyData, and choose Request My Observations. eBird will email you a link to a .zip file containing your complete sightings history. Open the email, click the link, and save the file somewhere easy to find. Yearbirder can open the .zip file directly — there is no need to unzip it first. By default, most browsers will save the file in your Downloads folder.

Step 2 — Open your data in Yearbirder

Launch Yearbirder. Click the Open button on the toolbar (or choose File → Open eBird data file…). Navigate to the .zip file you downloaded and click Open. Yearbirder loads your data and displays list of the species in the file.

Step 3 — Generate your first list

Browse through the options on the filter on the left side of the screen. Set a few filter options, like county or family, and then click the Species button on the toolbar. A new window opens showing the species you have recorded, sorted taxonomically, along with the first date, most recent date, and checklist count for each. You can click on the column headers to sort the columns. You can also right-click on any information in the list to send that information to the filter.

Step 4 — Explore further

  • Click Locations to see all your sighting locations plotted on an interactive map.
  • Click Date Totals to see which years, months, and individual dates you recorded the most species.
  • Optionally, add your bird photos and sound recordings to Yearbirder's media catalog (see Section 20 and Section 26) so you can browse photos and listen to recordings alongside their sighting data.

You are up and running. Everything else in this guide describes these features in detail.

Note that if some checklists include exotic species, the totals that Yearbirder calculates may not match the totals reported by eBird. The data file you download from eBird does not specify which sightings are exotics, so Yearbirder cannot exclude them from its totals.

2. The Main Window

Yearbirder allows many report, map, and graph windows to be open at the same time. The main window contains:

  • A menu bar across the top with menus for File, Filter, Lists, Reports, Graphs, Maps, Photos, Windows, and User Guide.

  • A Sighting Filter panel docked on the left side.
  • A Media Filter panel docked on the right side.
  • A large central area where all open windows (lists, reports, maps, photos) are displayed.
  • A status bar at the very bottom showing the current data file and record counts.

3. Loading Your eBird Data

Opening a data file

Choose File → Open eBird data file… or click the Open toolbar button. Yearbirder accepts the standard eBird download data file (typically named something like MyEBirdData.zip).

Loading time depends on the size of your dataset. A typical dataset of 10,000–50,000 sightings loads in a few seconds. Once loaded, the status bar shows the total number of sightings and species.

To avoid having to open your eBird data file manually every time you use Yearbirder, save it as a preference (see Section 39 — Saving Preferences) so that Yearbirder opens it automatically at startup.

Closing a data file

Choose File → Close eBird data file to unload the current dataset. Any open windows that depend on the data will close automatically.

What data is loaded

Yearbirder reads the following fields from your eBird data file:

  • Species common name and scientific name
  • Taxonomic order, family, and order
  • Observation date and time
  • Country, state/province, county, and location name
  • Location coordinates (latitude/longitude)
  • Checklist ID
  • Number of individuals counted

4. The Sighting Filter

The Sighting Filter panel is the primary way to focus every report and list on the data you care about. It is docked on the left side of the main window and always visible. All open windows update immediately whenever you change any filter setting.

Location filters

The location filters are hierarchical — selecting a more specific level automatically constrains the broader levels. You can filter at any one of these levels:

FilterDescription
RegionA broad geographic region (e.g., North America)
CountryA specific country (e.g., United States)
StateA state or province
CountyA county or sub-region within a state
LocationA specific named eBird location

Select **All** in any drop-down to clear that level's filter.

Taxonomic filters

FilterDescription
OrderBird order (e.g., Passeriformes)
FamilyBird family (e.g., Parulidae – Wood-Warblers)
SpeciesA single species name
Name SearchFree-text search; matches any part of a species' common name

The taxonomic filters also follow a hierarchy for the purposes of the window title: if a Species is selected, Family and Order are not shown in the title (they are implied). If only a Family is selected, Order is not shown. Only the most specific level selected is displayed.

Date filters

Seasonal range filters

Seasonal filters let you examine a recurring window within each year regardless of the year itself — useful for studying migration patterns.

FilterDescription
Seasonal Range OptionsQuick presets for common seasonal windows
Start Seasonal RangeMonth and day marking the start of the seasonal window

For example, setting a seasonal range of May 1 – May 31 shows all May sightings across all years.

My County and My Patch buttons

If you have configured a My County or My Patch in Preferences, two quick-jump buttons appear at the very top of the Sighting Filter. Clicking My County sets the filter to your saved county (and automatically fills in its state, country, and region above it). Clicking My Patch does the same for your saved specific birding location, including its county, state, country, and region. These buttons are hidden when no value has been set. To configure them, see Section 39 — Saving Preferences.

Clearing filters

  • Click Clear all filters on the toolbar to reset every filter at once.
  • Individual filters can be cleared by selecting the **All** option in their drop-down.

The Media Filter panel is hidden until you open a media catalog (see Section 20), at which point it appears automatically on the right side of the main window. It filters photo-related results in addition to the Sighting Filter — only photos that match both the Sighting Filter and the Media Filter are shown. Press Cmd-M (Mac) or Ctrl-M (Windows) to show or hide the panel at any time.

All Media Filter fields work as range selectors. Select **All** to disable a particular filter.

The bit-depth checkboxes are a multi-select: leaving them all unticked disables the filter, while ticking two or more shows recordings matching any of the ticked depths.

9. Families Window

Open with Lists → Families or the Families toolbar button.

The Families window has two panes:

  • Left pane: A scrolling list of every bird family represented in your sightings under the current filter.
  • Right pane: The species from the selected family, along with sighting statistics.

Click a family name in the left pane to populate the right pane. This is an efficient way to browse your sightings by taxonomic family — for example, quickly seeing all your warbler or shorebird records.

The window title shows the number of families, e.g., "Families: New York (12 Families)".

10. Date Totals

Open with Reports → Date Totals or the Date Totals toolbar button.

The Date Totals window presents three side-by-side tables:

Year Totals

One row per year, showing how many species and checklists you recorded in that year.

Month Totals

One row per calendar month (January through December), showing totals across all years.

Date Totals

One row per individual date on which you submitted a checklist, showing species and checklist counts for that date.

All three tables are sortable by any column. This report is useful for identifying your most productive years, your best months for birding, and your record single-day species counts.

The window title shows the total number of unique dates, e.g., "Date Totals: All species, locations, and dates (365 Dates)".

20. Adding Photos to Yearbirder

Yearbirder uses a media catalog to associate photos on your hard drive with your eBird sightings. Once photos are associated, Yearbirder can show you all the photos you have taken of a species, or the photos from a particular day or location. The catalog stores file paths, dates, species names, ratings, and camera information. Think of it as a photo library that sits alongside your eBird data.

Adding photos to Yearbirder

  1. Choose File → Add photos….
  2. A file dialog opens. Navigate to the folder containing your bird photos and select one or more JPEG files. You can select multiple photos at once — there is no need to add them one at a time:
    • Mac: hold Command (⌘) and click to select individual photos, or hold Shift and click to select a contiguous range.
    • Windows: hold Ctrl and click to select individual photos, or hold Shift and click to select a contiguous range.
  3. For each photo, Yearbirder asks you to confirm the associated bird species and checklist. To make this easier, it uses each photo's filename and EXIF date/time to suggest the most likely species — so in many cases you only need to confirm the suggestion. Yearbirder recognises eBird species codes in filenames (e.g. rufhum_20240514.jpg), BBL four-letter codes, and common-name words. If the correct sighting does not appear as an option, make sure that sighting is logged in eBird; you cannot associate a photo with a sighting that is not in your data.
  4. Your associations are saved to the media catalog automatically as you make them. The first time you add media with no catalog open, Yearbirder prompts you to choose a name and location for a new catalog file (a .jsonl file); from then on it saves there automatically. Remember where you saved it — you will open it again the next time you use Yearbirder.

Opening an existing media catalog

Choose File → Open media catalog… and navigate to your saved catalog file. Yearbirder loads all photo associations and EXIF data. The Media Filter panel becomes active.

To avoid opening your media catalog manually every time, save its path as a preference (see Section 39 — Saving Preferences) so that Yearbirder opens it automatically at startup.

Saving changes

Changes to your photo associations are written to the media catalog automatically as you make them, so there is no separate save step. To keep a safety copy, choose File → Backup media catalog…, which writes a dated backup copy of your catalog without disturbing the working file.

Closing the media catalog

Choose File → Close media catalog. This unloads all photo data from memory. The Media Filter panel becomes inactive.

Adding more photos

With a media catalog already loaded, choose File → Add photos… to import additional photos. The new associations are merged into the existing catalog; save afterwards. After you select files, Yearbirder reports how many are already tracked and how many are new — so you can confirm you have selected the right files before any associations are created.

Managing photos

Choose File → Manage Photos… to open the Manage Photos window, where you can view and edit the details of individual photos that match the current filter — for example, to reassign a photo to a different species or correct a date.

Updating EXIF data

If you have moved or re-exported your photo files, choose File → Refresh camera data from photos. Yearbirder re-reads the EXIF metadata from every file referenced in the catalog and updates its records. This is also useful after photo editing software writes new EXIF tags.

Cleaning up missing references and unused cache

If photos or recordings have been moved or deleted from your hard drive, Yearbirder may show broken references. Use File → Compact catalog and cache… to scan for and remove any associations pointing to files that no longer exist.

The same command also clears unused images from Yearbirder's on-disk cache — the thumbnails and spectrograms it renders once and reuses so media appears instantly. Any cached image that no longer matches a file in the currently open catalog is deleted, reclaiming disk space left behind by media you have removed. Your original photo and recording files are never touched; only Yearbirder's preview images are affected, and any that are still needed are re-created automatically the next time you view that media.

Because the cache is shared across catalogs, running this command while one catalog is open will also clear cached images belonging to a different catalog. This is harmless — nothing is lost — but the other catalog's photos and recordings may take a moment to re-cache the first time you browse them after switching back to it.

What the media catalog contains

The catalog stores one record per photo, including:

  • File path to the JPEG
  • Associated species common name
  • Associated sighting date
  • Your personal rating
  • Camera model (from EXIF)
  • Lens model (from EXIF)
  • Shutter speed (from EXIF)
  • Aperture (from EXIF)
  • Focal length (from EXIF)
  • ISO (from EXIF)

You can open the catalog file in a text editor or spreadsheet to inspect values, but be careful to preserve its structure.

26. Adding Recordings to Yearbirder

In addition to photos, Yearbirder can associate your personal bird sound recordings with your eBird sightings. Recordings are stored in the same media catalog as your photos (see Section 20) — there is no separate file to manage. Once a recording is associated, Yearbirder can show you every recording you have made of a species, play it back, and display it as a spectrogram.

Recordings must be in WAV format (mono or stereo). As with photos, Yearbirder stores a reference to each file's location on your computer, not a copy — your original recordings stay where they are.

Adding recordings

  1. Choose File → Add recordings….
  2. A file dialog opens. Navigate to the folder containing your recordings and select one or more WAV files. You can select several at once (hold Command / Ctrl to pick individual files, or Shift to select a contiguous range).
  3. For each recording, Yearbirder asks you to confirm the associated species, location, date, and time. As with photos, it uses each file's name and timestamp to suggest the most likely sighting, so you usually only need to confirm. The sighting must already exist in your eBird data.
  4. Set an optional rating (your personal quality score) for each recording.
  5. Your additions are saved to the media catalog automatically. (If no catalog is open yet, Yearbirder prompts you to create one.)

After you select files, Yearbirder reports how many of them are already in your catalog and how many are new, so you can confirm your selection before any associations are created.

Managing recordings

To review or edit the details of recordings already in your catalog, open the Manage Recordings window — see Section 29 — Managing Your Recordings.

What a recording record contains

  • File path to the WAV recording
  • Associated species common name
  • Associated sighting location, date, and time
  • Your personal rating
  • Duration and channel count (Mono / Stereo), read from the file

27. Browsing and Playing Recordings

Your recordings can be browsed two ways, and both show every recording matching the current Sighting Filter and Media Filter. The Recordings menu appears whenever an eBird data file is open.

Browse Cards

Open with Recordings → Browse Cards. Shows one recording per row, with the full details alongside it.

Each row displays:

  • A spectrogram — a visual representation of the recording, with time along the horizontal axis and frequency (pitch) along the vertical axis. Louder sounds appear darker.
  • A Play / Pause button and a scrubber bar beneath the spectrogram.
  • A caption with the species name, scientific name, location, date, duration, and your rating.

Browse Grid

Open with Recordings → Browse Grid or the Recordings toolbar button. The same recordings as Browse Cards, arranged as a grid of spectrograms rather than a single column — quicker to scan when a filter returns a lot of them, and the view to reach for when you are hunting for one particular cut among many.

Every cell keeps its own Play / Pause button and scrubber, so you can audition a recording without leaving the grid, and the red cursor line sweeps across the cell's spectrogram exactly as it does on a card. Only one recording plays at a time: pressing Play on a second cell stops the first and resets its scrubber.

The species name appears beneath each spectrogram, with the full details — scientific name, location, capture date and time, and rating — shown on hover. Click a spectrogram to open the Recording Enlargement view for that recording.

The window opens three columns wide. Widen or narrow it and the grid reflows to fit as many columns as the space allows, without re-rendering any spectrograms. Both views offer the same four sorting options, and both update immediately when a recording is deleted, removed from the catalog, or reassigned to a different species.

Playback

Click Play to listen to a recording. A red cursor line sweeps across the spectrogram in real time to show your position, and the scrubber tracks along with it. Drag the scrubber to jump to any point in the recording. Click Pause to stop; clicking Play on a different recording switches to it.

Audio quality and formats

Yearbirder plays WAV recordings across the full range of bit depths a field recordist is likely to use — 16-bit, 24-bit, and 32-bit integer, as well as 32-bit float (the format used by recorders such as the Zoom F3). It also handles a wide span of sample rates, from low rates up through high-resolution 96 kHz and 192 kHz. Each recording is decoded at its full resolution, so the fine detail and wide dynamic range of high-bit-depth files are preserved.

You don't need to configure anything for playback to sound right. Yearbirder automatically conforms to your computer's current audio output settings: it plays in high-quality 32-bit float when your sound device supports it, and at the sample rate your device is currently set to. When a recording's sample rate differs from your device's — for example, playing a 96 kHz recording while your output is set to 48 kHz — Yearbirder converts it on the fly using a high-quality resampler, so it always plays at the correct pitch and speed. If you switch output devices or change your device's audio settings while Yearbirder is running, playback adjusts to the new settings automatically.

Opening a recording for detailed study

Click any spectrogram to open the Recording Enlargement view (see Section 28), where you can zoom, adjust the frequency range and contrast, and examine the sound in detail.

Sorting recordings

28. The Recording Enlargement View

Playback

The three control sliders

Three sliders let you adjust the view continuously and instantly — there is no waiting for the image to redraw:

Date and time are taken from the file's own metadata (EXIF for photos, embedded metadata for recordings). When a file has no embedded date or time, Yearbirder automatically falls back to the date and start time of the eBird checklist the file is attached to — so a name part is filled in whenever possible.

A Sample line below the parts shows a live preview of what the first file's new name would look like as you adjust your choices.

How duplicate names are differentiated

When two or more files would end up with the same proposed name, Yearbirder differentiates them automatically — you don't have to configure anything:

  1. Tenths of a second first. If a Time part is in use and the clashing files carry subsecond information in their metadata, Yearbirder appends the tenths-of-a-second digit so each name becomes unique (for example, …_07-23-452 and …_07-23-457). This keeps the names meaningful and in true chronological order.
  2. Numeric suffix as a fallback. If tenths aren't available, or two files still match after adding tenths (for instance, frames from a burst with identical subsecond stamps, or names with no Time part at all), Yearbirder appends _1, _2, and so on — zero-padded when needed so they sort correctly.

The Status column (below) shows which files are receiving a suffix, so you always see how a clash is being resolved before you commit.

Options

  • Remove spaces — strips spaces from species and location name components so the filename contains no whitespace (on by default).
  • Shorten location name to the first punctuation mark — trims long location names at the first comma, dash, colon, @, or parenthesis. For example, "Central Park, Manhattan, NY" becomes "Central Park".

36. Rebuild Media Thumbnails

To make your photos and recordings appear quickly, Yearbirder keeps a cache of the thumbnails it shows in the photo browsers — one sized for Browse Cards and a smaller one for Browse Grid — and the spectrograms it shows in the Recordings browser and the Recording Enlargement view. This cache is built automatically: items are added to it when you first import them, and refreshed automatically if a file changes. You normally never need to think about it.

Occasionally you may want to rebuild the cache from scratch — for example, if you edited a photo with software that kept the original file's date and size unchanged, or if you simply want to be certain every cached image is current. Choose File → Rebuild thumbnail cache….

Yearbirder asks you to confirm, then clears the existing cache and regenerates both thumbnail sizes for every photo and a spectrogram for every recording in your media catalog. A progress bar shows how far along it is. The work runs in the background, so the rest of Yearbirder stays responsive, and you can keep working while it finishes.

This command is purely a convenience for refreshing the cache. It does not change, move, or delete any of your original photo or recording files, and it does not alter your media catalog — it only rebuilds the cached preview images Yearbirder draws from.

38. Tips and Tricks

Keep multiple windows open for comparison

Yearbirder allows many windows to be open at the same time. For example, open a Species List filtered to one location, then open a second Species List filtered to a different location, and use Windows → Tile Windows to view them side by side.

Seasonal migration analysis

Set the seasonal range filter to a narrow window (for example, May 1–May 15) and open the Date Totals report. You will see how your spring migration counts vary from year to year across those same two weeks.

Finding your best single day

Open Date Totals with no filters set and sort the Date Totals table by Species (descending). Your highest single-day species count rises to the top.

Tracking a family across geography

Set the Family filter to a family you are interested in (e.g., Shorebirds), then open the US States Choropleth. The shading immediately shows which states you have recorded shorebirds in.

Combining Name Search with other filters

The Name Search field accepts a partial name and filters the Species List in real time. This is the fastest way to find a species when you are not sure of its exact name — type "thrush" and all thrushes appear regardless of which family they belong to.

Using graphs to understand your birding patterns

  • Seasonal Occurrence + species filter: select a favourite migrant species in the Species filter, then open Graphs → Timing & Seasonality → Seasonal Occurrence. You will immediately see whether your records show the species arriving earlier or later in recent years.
  • Outing Effort + location filter: set a location filter and open Graphs → Checklists → Outing Effort. Clusters of dots reveal your typical productivity at that site — and outlier dots (many species in a short time, or few species in a long session) are worth investigating.
  • New Species Each Year + location filter: filter to a county or location you visit regularly and open Graphs → Species → New Species Each Year. Bars with a large bright-blue new-species segment were standout years for that location.
  • Species growth with no filter: open Graphs → Species → Species Growth Over Time with all filters cleared to see your all-time life-list growth curve. The slope flattens as you become a more experienced birder — steep jumps often correspond to trips to new regions.

Photo workflow tips

  • Rate your photos immediately after a field outing while the session is fresh. Use the Enlargement view to assign ratings of 1–5.
  • Back up your media catalog file alongside your eBird data file. It is the only record of your photo associations.
  • Use the Media Filter to find your best shots: set Rating Range to 4–5 and open the Photos gallery to see only your highest-rated photos.
  • Refresh camera data after any significant photo editing session or file reorganisation to keep the metadata in sync.

Audio Calibration

Bluetooth headphones and some audio interfaces add playback latency that Yearbirder has no way to measure on its own — the sound reaches your ears later than Yearbirder thinks it does, so the red cursor in a recording's spectrogram appears to run ahead of what you hear. This tab lets you correct for that, separately for each audio output device, with a short tick-and-flash test.

  1. Select the output device you want to calibrate (shown at the top as Current audio device — switch devices on your computer to calibrate a different one).
  2. Click Start Test. A tick plays on a loop while a box on screen flashes in time with it, driven by the same clock the spectrogram cursor uses.
  3. Drag the slider (or type a value directly into the millisecond field) until the sound and the flash feel simultaneous. The offset applies live as you drag, so you can fine-tune by ear.
  4. Click Save to store that offset for the current device.
  5. Click Start Test again (it becomes Stop Test while running) to end the test tone.

Wired speakers and headphones usually need an offset at or near 0 ms; Bluetooth devices typically need somewhere in the range of 150–500 ms. Every device you have calibrated appears in a table beneath the test controls, showing its saved offset (editable directly in the table) and a Remove button to delete that device's calibration. Once saved, a device's offset is applied automatically, in every Recording Enlargement window, whenever you play a recording through that device.
